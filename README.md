# Yarka Prod

The website of Yarka Prod, the developer of **Freya: Air Defence**, an air-defence strategy game for Android: https://yarka28.github.io

- `index.html`, `site.css`: the page (Ukrainian and English);
- `freya/privacy/`: the game's privacy policy (https://yarka28.github.io/freya/privacy/).

Built from the game's repository (`store/site/`, `tools/make_site.py`). The fonts are Fira Sans (SIL Open Font License, `fonts/OFL.txt`).
